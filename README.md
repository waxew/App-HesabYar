# حسابیار (HesabYar)

حسابیار یک اپ اندرویدی فارسی، آفلاین‌محور و قابل‌گسترش برای محاسبات خرید، تخفیف، سود، قیمت‌گذاری و مدیریت سبک اطلاعات مالی روزمره است.

## نسخه 2.0.0

- `versionCode = 3`
- `applicationId = com.waxew.hesabyar`
- Kotlin + Jetpack Compose + Material 3
- `minSdk 24` / `targetSdk 35`

این نسخه یک Major Update نسبت به 1.0.1 است و با همان Application ID و همان کلید Release منتشر می‌شود تا روی نسخه قبلی نصب شود و داده‌های محلی کاربر حفظ شوند.

## Build

CI گیت‌هاب قبل از ساخت APK تست‌های Unit را اجرا می‌کند.

```bash
gradle :app:testDebugUnitTest
gradle :app:assembleDebug
gradle :app:assembleRelease
```

برای Release امضاشده، اطلاعات Keystore باید خارج از GitHub و از Environment داده شوند:

- `HESABYAR_KEYSTORE_FILE`
- `HESABYAR_KEYSTORE_PASSWORD`
- `HESABYAR_KEY_ALIAS`
- `HESABYAR_KEY_PASSWORD`

کلید خصوصی Release در مخزن عمومی نگهداری نمی‌شود.

## ساختار مهم

- `CalculationEngine.kt`: فرمول‌های پایه
- `AdvancedCalculationEngine.kt`: فرمول‌های فروشنده/عمده/سناریوها
- `CalculatorScreens.kt`: صفحات محاسبات پایه
- `AdvancedScreens.kt`: خریدار، فروشنده، دفترچه قیمت، Scanner، Reports و Data Tools
- `AdvancedRepositories.kt`: داده محلی سبد خرید و Price Book
- `DataTransferManager.kt`: PDF/CSV/XLSX و Backup/Restore
- `HesabYarWidgetProvider.kt`: Widget صفحه اصلی
- `UpdateChecker.kt`: بررسی نسخه جدید از `distribution/latest.json`

## آپدیت‌پذیری

برای هر نسخه بعدی:
1. `applicationId` تغییر نکند.
2. `versionCode` افزایش یابد.
3. APK با همان Keystore حسابیار امضا شود.
4. SharedPreferences موجود بدون Migration حذف/تغییر نام داده نشوند.
5. بعد از آماده شدن APK نهایی، `distribution/latest.json` به نسخه جدید اشاره کند.
