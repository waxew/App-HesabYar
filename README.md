# حسابیار (HesabYar)

حسابیار یک برنامه اندرویدی فارسی برای محاسبات سریع خرید، تخفیف، سود، قیمت‌گذاری و درصد است. رابط برنامه با Kotlin، Jetpack Compose و Material 3 ساخته شده و محاسبات اصلی بدون اینترنت انجام می‌شوند.

## نسخه فعلی سورس

`1.0.1` با `versionCode = 2`

این نسخه یک Patch روی 1.0.0 است و با همان `applicationId` و همان کلید Release منتشر می‌شود تا به‌صورت Update روی نسخه قبلی نصب شود و تنظیمات/تاریخچه کاربر باقی بمانند.

## ساختار منوی همبرگری

1. خانه
2. تنظیمات
3. معرفی به دوستان
4. درباره ما
5. تماس با ما
6. درباره نرم افزار

در تنظیمات، بخش «اعلان‌ها» کنترل می‌کند که برنامه در شروع اجرا وجود نسخه جدید را بررسی کند یا نه.

## رفتار دکمه Back

Back دیگر داخل ابزارها باعث خروج ناگهانی برنامه نمی‌شود. ترتیب رفتار:

1. اگر Drawer باز باشد، Drawer بسته می‌شود.
2. اگر یک ماشین‌حساب باز باشد، به صفحه قبلی برمی‌گردد.
3. اگر تاریخچه/تنظیمات/درباره‌ها باز باشند، به خانه برمی‌گردد.
4. فقط وقتی کاربر روی صفحه خانه است، Back می‌تواند برنامه را ببندد.

## موتور محاسبات

فرمول‌ها از UI جدا و داخل `CalculationEngine.kt` قرار گرفته‌اند. این ساختار دو مزیت دارد:

- تست خودکار فرمول‌ها ساده است.
- در نسخه آینده، Widget اندروید می‌تواند همین Engine را بدون تکرار فرمول استفاده کند.

تست‌های فعلی موارد مهمی مثل تخفیف ترکیبی، تفاوت Margin/Markup، Margin هدف، مالیات، درصد تغییر و نقطه سربه‌سر را پوشش می‌دهند.

## Build روی لپ‌تاپ

پروژه را در Android Studio باز کنید و Gradle Sync را انجام دهید. اگر Gradle Wrapper در محیط شما ساخته نشده است، Android Studio/Gradle 8.9 را انتخاب کنید.

Build تستی:

```bash
gradle :app:testDebugUnitTest :app:assembleDebug
```

Build Release بدون امضا:

```bash
gradle :app:assembleRelease
```

برای Build امضاشده، متغیرهای زیر را قبل از Gradle تنظیم کنید:

- `HESABYAR_KEYSTORE_FILE`
- `HESABYAR_KEYSTORE_PASSWORD`
- `HESABYAR_KEY_ALIAS`
- `HESABYAR_KEY_PASSWORD`

کلید خصوصی و رمزها **نباید** داخل مخزن عمومی GitHub Commit شوند.

## آپدیت‌پذیری

برای هر نسخه بعدی:

1. `applicationId` تغییر نکند.
2. `versionCode` حتماً افزایش یابد.
3. APK Release با همان کلید امضای حسابیار امضا شود.
4. `versionName` به نسخه جدید تغییر کند.
5. `distribution/latest.json` بعد از آماده شدن APK نهایی به‌روزرسانی شود.
6. نام کلیدهای SharedPreferences موجود بدون Migration تغییر نکند تا تنظیمات/تاریخچه حفظ شوند.
