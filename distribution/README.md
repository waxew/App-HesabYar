# پوشه distribution

این پوشه فایل‌های مربوط به انتشار و سیستم آپدیت حسابیار را نگه می‌دارد.

- `latest.json`: نسخه‌ای که برنامه هنگام اجرا برای پیدا کردن آپدیت جدید می‌خواند.
- APK پابلیش هر نسخه پس از Build و امضای معتبر می‌تواند در همین پوشه قرار گیرد.

نکته مهم: فایل JSON استاندارد امکان Comment ندارد؛ بنابراین توضیح ساختار آن در همین README نگهداری می‌شود.

ساختار `latest.json`:

- `versionCode`: عدد صحیح که در هر انتشار باید افزایش پیدا کند.
- `versionName`: نسخه قابل نمایش به کاربر، مثل `1.0.1`.
- `downloadUrl`: لینک فایل APK پابلیش یا صفحه انتشار.
- `notes`: توضیح کوتاه تغییرات برای Dialog آپدیت.
