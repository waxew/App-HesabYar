# HesabYar Roadmap

نسخه 3.0.0 همه موارد Roadmap قبلی را وارد سورس کرده است:
- Marketplace profiles and fee rules
- Installment/cash comparison
- Price analytics, best price, personal inflation, shrinkflation
- Margin-drop warning and What-if slider
- Offline invoice + PDF
- Multiple business profiles
- CSV/XLSX import
- Encrypted backup/restore
- Structured OCR parsing
- Responsive widget + Android shortcuts + Quick Settings tile
- Favorites/search
- Unit/currency conversion
- Smart Persian command parser
- Cash Check dashboard

موارد بعدی:
- اختیاری: Sync ابری و ورود کاربر
- نرخ ارز آنلاین فقط با منبع قابل اعتماد و انتخاب کاربر
- UI screenshot regression و تست‌های instrumentation گسترده‌تر
